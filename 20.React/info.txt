React is a front-end library that helps us build user interfaces from compoenets

We can assemble smaller componenets to build larger applications.

Components combine HTML and logic into a single reusable function.

Components:-
Ex:- function Header(){
    return <h1>"I am a header component!!"</h1>
}
Functions that know how to render themselves into HTML.

JSX:-
-> JSX is a syntax extension for JavaScript.
-> It allows us to write markup that looks like HTML directly inside of our HTML.
-> It's not legal JS on oits own, so it must be transpiled.
