JS is single threaded
It means at any given point in time, that single JS thread is running at most one line of JS code.

--> Browsers come with WebAPIs that are able to handle certain tasks in the background(like making requests or setTimeout)
--> The JS call stack recognizes these Web API fn.s and passes them off to the browser to take care of.
--> Once the browser finishes those tasks, they return and are pushes onto the stack as a callback.
